    Add a New Source Type (Adapter + Analyzer)¶

    This guide shows you how to extend Layer 1 with a brand-new source type end to end: a fetch adapter, an analysis analyzer, and registration in both registries. Once done, any Source with your new source_type will scan and produce CandidateSignal rows like the built-in types. For the architecture behind adapters and analyzers, see Layer 1 — Source Scanning.

    Prerequisites¶

    • A local dev checkout with the app installed (pip install -e ".[dev]").
    • Familiarity with the adapter/analyzer contracts (app/adapters/base.py, app/analysis/contracts.py).
    • Config loaded so you have a competitor to attach a test source to.

    Correct paths (doc-drift correction)

    CLAUDE.md refers to app/analyzers/ and flat <type>_adapter.py files — that is outdated and wrong. The real layout is per-type packages:

    • Adapter: app/adapters/<type>/adapter.py
    • Analyzer: app/analysis/<type>/analyzer.py
    • Register in app/adapters/registry.py AND app/analysis/registry.py

    Step 1 — Write the adapter¶

    Create app/adapters/<type>/adapter.py. The adapter fetches and normalizes; it does no LLM work. Implement the SourceAdapter protocol — a single scan() method returning an AdapterScanResult.

    # app/adapters/<type>/adapter.py
import httpx
from app.core.config import get_settings
from app.schemas.adapter import (
    AdapterScanResult, FetchedSourceArtifact,
    AdapterNormalizedDocument, AdapterDiscoveredItem,
)

ADAPTER_NAME = "<type>"

class MyAdapter:
    def scan(self, source, competitor, context: dict) -> AdapterScanResult:
        settings = get_settings()
        cfg = source.config_json or {}
        # All adapter HTTP uses verify=False (deliberate — corporate proxy).
        resp = httpx.get(source.url, timeout=settings.HTTP_TIMEOUT_SECONDS, verify=False)
        return AdapterScanResult(
            adapter_name=ADAPTER_NAME,
            source_type="<type>",
            fetched_artifacts=[FetchedSourceArtifact(...)],
            normalized_documents=[AdapterNormalizedDocument(...)],
            discovered_items=[AdapterDiscoveredItem(
                item_type="<some SourceItemType>",
                url="...",
                fingerprint="...",   # REQUIRED — stable dedup key per item
            )],
            warnings=[],
            metadata={},
        )

    Info

    verify=False on adapter HTTP is intentional (corporate proxy). Do not "fix" it. Reuse helpers in app/core/hashing.py and app/core/urls.py for content hashes and URL canonicalization.

    Every AdapterDiscoveredItem must carry a fingerprint — it is the unique key for SourceItem (UNIQUE(source_id, fingerprint)) and drives appearance/disappearance detection.

    Step 2 — Write the analyzer¶

    Create app/analysis/<type>/analyzer.py. Implement the SourceAnalyzer protocol's analyze() method returning a SourceAnalysisResult. The analyzer loads previous state, computes deterministic deltas, runs the cheap gate, and only calls the LLM when the gate says so.

    # app/analysis/<type>/analyzer.py
from app.analysis.cheap_gate import evaluate_change_package
from app.schemas.analysis import SourceAnalysisResult

class MyAnalyzer:
    def analyze(self, source, competitor, scan_run, adapter_result,
                persisted_scan_objects, repositories, llm_provider) -> SourceAnalysisResult:
        # 1. Load previous state via repositories lambdas
        prev_items = repositories["list_previous_items_for_source"](source.id)

        # 2. First scan → emit only a baseline_created delta, NO signals
        # 3. Build LowLevelDeltaDraft + ChangePackage drafts deterministically

        # 4. Cheap gate decides per change package
        decision = evaluate_change_package(change_package)
        # -> no_action | suppress_noise | llm_review | candidate_without_llm

        # 5. Only on llm_review, call the LLM (structured JSON)
        if decision == "llm_review":
            result = llm_provider.complete_json(
                prompt_name="<type>_interpreter", prompt_version="v1",
                system_prompt="...", user_payload={...}, response_schema={...},
            )
            # record an LLMTraceDraft; build a CandidateSignalDraft

        return SourceAnalysisResult(
            low_level_deltas=[...], change_packages=[...],
            candidate_signals=[...], llm_traces=[...],
            warnings=[], metadata={},
        )

    Notes:

    • repositories is a dict of accessor lambdas (list_previous_documents_for_source, list_previous_items_for_source, feedback_suppressions, db, …).
    • First scan of any source is baseline-only — emit a baseline_created delta and no candidate signals.
    • Put prompts in app/analysis/<type>/prompts.py. Adapters never call the LLM; analysis is the only LLM point in Layer 1.

    Step 3 — Register in BOTH registries¶

    This is the step most commonly missed. The source type string must appear in both factories.

    # app/adapters/registry.py  → build_default_adapter_registry()
registry["<type>"] = MyAdapter()

# app/analysis/registry.py  → build_default_analyzer_registry()
registry["<type>"] = MyAnalyzer()

    If either registration is missing, the worker resolves no adapter/analyzer and fails the job (_fail_job → retry → dead-letter).

    Step 4 — Add enums if needed¶

    If your adapter emits a new kind of item or artifact, add values to app/core/enums.py:

    • SourceType — add <type> so it validates on Source creation.
    • SourceItemType — if you discover a new item kind (e.g. podcast_episode).
    • ArtifactType — if you fetch a new raw format.

    Step 5 — Set metadata for telemetry¶

    The worker wraps your adapter and analyzer in observe_agent(...) with stage=source_type (adapter) and stage=f"{source_type}_analyze" (analyzer). Populate metadata on your results and call obs.set_output_count() where relevant so the observability screens show your new stage correctly.

    Test it¶

    Attach a test source with your new source_type to a competitor, then run a full local Layer 1 scan:

    ci-agent dev-run-once
ci-agent list-candidate-signals --limit 20 --verbose

    Remember: the first scan of a source emits only a baseline (no signals). Run it twice, changing the target between runs, to see deltas become candidate signals.
