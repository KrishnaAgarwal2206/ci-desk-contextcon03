    Configuration & Environment¶

    All runtime configuration lives in a single pydantic-settings Settings class (app/core/config.py). Values come from environment variables and an optional .env file, with sensible defaults baked in so the app runs offline in mock mode with no keys. This page lists every setting, grouped by subsystem, with its default and a placeholder example.

    How configuration resolves¶

    1. .env is resolved relative to the project root, not the working directory. The path is computed in code as Path(__file__).parent.parent.parent / ".env", so ci-agent and uvicorn pick up the same .env regardless of where you launch them.
    2. Settings is a singleton. get_settings() builds the Settings object once and caches it in a module global; every caller shares the same instance for the process lifetime.
    3. Unknown keys are ignored. Settings.Config sets extra = "ignore", so .env.example may be a subset and extra environment variables do not raise.
    4. Per-source YAML config overrides .env. Where a source's config_json block (from the competitor YAML) sets an option that also exists as an environment default — e.g. a news provider, query_budget, or bing_market — the per-source YAML value takes precedence for that source. Environment settings are the fallback.

    Danger

    Never print or commit real secrets. .env is gitignored and holds real API keys; .env.example is the safe, placeholder-only template. All examples on this page use placeholders such as <key> and https://<your-resource>.openai.azure.com. The local database (data/*.db) and blob store hold real competitor data and are never committed.

    Database & storage¶

    Variable Purpose Example
    DATABASE_URL SQLAlchemy connection URL. SQLite locally, Azure SQL in production. sqlite:///./data/ci_local.db
    LOCAL_BLOB_ROOT Filesystem root for the local blob store (raw artifacts, normalized docs). ./data/blob

    HTTP & runtime¶

    Variable Purpose Example
    USER_AGENT User-Agent header for outbound fetches. CompetitiveIntelligenceAggregator/0.1 respectful-public-monitoring
    HTTP_TIMEOUT_SECONDS Per-request HTTP timeout. 20
    POLITENESS_DELAY_SECONDS Delay between fetches during scope crawls. 2.0
    MAX_QUEUE_ATTEMPTS Retry attempts before a queued job is dead-lettered. 3
    ENVIRONMENT local or production; selects local vs Azure infra when a connection string is also set. local

    LLM¶

    Variable Purpose Example
    LLM_PROVIDER mock (offline, deterministic) or azure_openai. azure_openai
    AZURE_OPENAI_ENDPOINT Azure OpenAI resource endpoint. https://<your-resource>.openai.azure.com
    AZURE_OPENAI_API_KEY Azure OpenAI API key. <key>
    AZURE_OPENAI_MODEL Deployment name used as the model. gpt-4o

    News & social providers¶

    Variable Purpose Example
    NEWS_PROVIDER mock, tavily, or bing (auto-detection falls back Bing → Tavily → Brave → Mock). tavily
    TAVILY_API_KEY Tavily search API key. <key>
    BING_NEWS_API_KEY Bing News v7 API key. <key>
    BRAVE_SEARCH_API_KEY Brave Search API key. <key>
    APIFY_API_TOKEN Apify token for LinkedIn/Twitter social scraping actors. <token>

    Azure Service Bus & Blob¶

    Variable Purpose Example
    AZURE_SERVICE_BUS_CONNECTION_STRING Service Bus connection string; enables the queue in production. Endpoint=sb://<ns>.servicebus.windows.net/;...
    AZURE_SERVICE_BUS_QUEUE_NAME Queue name for source-scan jobs. source-scan-jobs
    AZURE_BLOB_CONNECTION_STRING Blob Storage connection string; enables Azure blob store in production. DefaultEndpointsProtocol=https;AccountName=<acct>;...
    AZURE_BLOB_CONTAINER Blob container for artifacts. ci-artifacts

    Note

    Azure infrastructure is selected only when ENVIRONMENT is not local and the relevant connection string is set. Otherwise the in-memory queue and local blob store are used. See Deployment.

    Delivery (SMTP & Teams)¶

    These live in Settings (not necessarily in .env.example).

    Variable Purpose Example
    SMTP_HOST SMTP server host. Empty → email delivery is skipped. smtp.<your-domain>.com
    SMTP_PORT SMTP port; 465 uses implicit SSL, otherwise STARTTLS. 587
    SMTP_USER SMTP username. <user>
    SMTP_PASSWORD SMTP password. <password>
    SMTP_FROM_EMAIL From address for digests and alerts. ci-agent@godrejcp.com
    TEAMS_WEBHOOK_URL Incoming webhook for Teams alerts. Empty → Teams delivery is skipped. https://<tenant>.webhook.office.com/...
    DEFAULT_RECIPIENTS Comma-separated default recipient list. a@x.com,b@x.com

    Feedback governance flags¶

    These govern the learning/governance subsystem (app/feedback/). Boolean flags default as shown; the REQUIRE_HUMAN_APPROVAL_* and REQUIRE_EVAL_* flags are the safety gates.

    Variable Purpose Default
    FEEDBACK_ENABLED Master switch for the feedback subsystem. True
    AUTO_ARCHIVE_FALSE_POSITIVE Archive a change automatically on a false-positive verdict (legacy path). True
    AUTO_CREATE_EXACT_URL_SUPPRESSION Auto-create an exact-URL suppression from feedback. True
    AUTO_APPLY_WEIGHT_PROPOSALS Apply weight-change proposals without human review. False
    AUTO_ACTIVATE_AGENT_POLICY_RULES Activate agent policy rules without human review. False
    MAX_POLICY_PACKS_PER_AGENT_RUN Cap on policy packs injected per agent run. 5
    MAX_PROMPT_POLICY_TOKENS Per-run token budget for injected policy text. 800
    MAX_POLICY_RULES_PER_PACK Cap on rules compiled into one pack. 8
    MAX_OPTIONAL_EXAMPLES_PER_AGENT_RUN Cap on optional examples injected per run. 2
    MAX_ACTIVE_GLOBAL_RULES_PER_AGENT Cap on active global rules per agent. 10
    MAX_ACTIVE_SCOPED_RULES_PER_AGENT Cap on active scoped rules per agent. 50
    REQUIRE_HUMAN_APPROVAL_FOR_PROMPT_CHANGES Gate prompt/policy changes on human approval. True
    REQUIRE_HUMAN_APPROVAL_FOR_DOMAIN_SUPPRESSION Gate domain-wide suppressions on human approval. True
    REQUIRE_HUMAN_APPROVAL_FOR_GLOBAL_WEIGHT_CHANGES Gate global weight changes on human approval. True
    REQUIRE_EVAL_BEFORE_POLICY_ACTIVATION Require an eval run before a policy pack can activate. True
    DEFAULT_SUPPRESSION_EXACT_URL_TTL_DAYS TTL for exact-URL suppressions (None = no expiry). None
    DEFAULT_SUPPRESSION_EVENT_FINGERPRINT_TTL_DAYS TTL for event-fingerprint suppressions. 90
    DEFAULT_SUPPRESSION_DOMAIN_TTL_DAYS TTL for domain suppressions (None = no expiry). None
    POLICY_PACK_VERSION_PREFIX Prefix for compiled policy-pack version labels. v

    A minimal real-LLM .env¶

    LLM_PROVIDER: azure_openai
AZURE_OPENAI_ENDPOINT: https://<your-resource>.openai.azure.com
AZURE_OPENAI_API_KEY: <key>
AZURE_OPENAI_MODEL: gpt-4o
NEWS_PROVIDER: tavily
TAVILY_API_KEY: <key>

    Everything else can stay at its default. Tests run fully offline with no keys (LLM_PROVIDER=mock, NEWS_PROVIDER=mock).

    Permissive SSL is deliberate¶

    Info

    All outbound adapter HTTP uses httpx with verify=False, and the email delivery path builds a permissive SSL context (check_hostname=False, CERT_NONE). This is an intentional accommodation for the corporate proxy environment — do not "fix" it by enabling verification. It is a known, load-bearing setting, not an oversight.
