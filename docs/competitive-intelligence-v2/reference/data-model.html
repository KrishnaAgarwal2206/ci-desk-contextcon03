    Data Model & Enums¶

    Every persistent entity is a SQLAlchemy model in app/db/models.py, grouped below by subsystem. This page is a dry, table-by-table inventory of the models and their key columns plus the shared enum values. For how these entities relate and flow into one another — the lineage chain and the entity-relationship diagram — see Data model & lineage.

    Conventions¶

    • Primary keys are UUID strings (String columns defaulting to str(uuid.uuid4())), not integers.
    • JSON columns carry the _json suffix (e.g. aliases_json, evidence_json, weights_json, metadata_json) and hold lists or dicts.
    • Timestamps are naive UTC (created_at, updated_at, plus per-entity *_at columns).
    • All database access flows through app/db/repositories.py. Routes and workers call repository functions rather than issuing raw ORM queries; the CLI inspection commands are the only routine exception.
    • Status columns are plain strings validated against the enums documented at the end of this page.

    Layer 1 — scanning tables¶

    Model Purpose Key columns
    Competitor A monitored competitor. name, tier, aliases_json, legal_names_json, known_domains_json, brand_names_json, product_names_json, leadership_names_json, industry_terms_json, negative_terms_json, custom_keywords_json, is_active
    Source One monitored source of a competitor. competitor_id, source_type, name, url, config_json, frequency, is_active, last_scan_at, last_successful_scan_at, last_scan_status
    ScanRun One scheduling/execution run across sources. triggered_by, status, started_at, completed_at, total_sources_enqueued, total_sources_completed, total_sources_failed
    SourceScanLog Per-source-per-run record. scan_run_id, source_id, competitor_id, status, adapter_name, analyzer_name, attempt_count, error_type, error_message, count columns, news_profile_version_id
    RawArtifact A fetched blob (raw text). artifact_type, uri, content_hash, fetched_url, canonical_url, status_code, headers_json
    NormalizedDocument Cleaned document derived from a raw artifact. raw_artifact_id, title, canonical_url, clean_text_uri, content_hash (drives change detection), block_count
    DocumentBlock A structural block of a normalized document. block_type, heading, heading_path_json, text, text_hash, position
    SourceItem A tracked item (page/article/job/post). item_type, external_id, url, canonical_url, title, first_seen_at, last_seen_at, current_status, fingerprint — UNIQUE (source_id, fingerprint)
    LowLevelDelta A deterministic detected change. delta_type, refs, evidence_json, deterministic_confidence
    ChangePackage A grouped delta with gate outcome. source_type, package_type, delta_ids_json, title, context JSONs, gate_decision, gate_reasons_json, llm_prompt_name
    LLMTrace One LLM call record. provider, model, prompt_name, prompt_version, input_hash, output_json, token_usage_json, latency_ms, error_message
    CandidateSignal The Layer 1 output / Layer 2 input. scan_run_id, source_id, competitor_id, source_type, primary_delta_id, change_package_id, signal_type, preliminary_category, title, summary, entities_json, evidence_json, confidence, llm_used, llm_trace_id, status, dedup_fingerprint

    Layer 2 — intelligence tables¶

    Model Purpose Key columns
    CandidateSignalArchive Rejected/archived candidate signals. archived signal fields, reason
    EvidenceBundle Hydrated evidence for a signal. candidate_signal_id, evidence items, source_authority
    NormalizedSignal Normalized form of a candidate signal. candidate_signal_id, evidence_bundle_id, event_action, claim_status, primary_entity, normalized_summary
    AtomicClaim An atomic claim with a stable fingerprint. normalized_signal_id, candidate_signal_id, evidence_bundle_id, event_fingerprint
    EventCluster A clustered real-world event. competitor_id, event_fingerprint (unique index ix_event_clusters_competitor_fingerprint), event_action, final_category, category_candidates_json, claim_status, source_count, cluster_confidence, status
    EventClusterSignalLink Cluster↔signal membership. UNIQUE (cluster_id, candidate_signal_id)
    EventEvidence Evidence attached to a cluster. cluster_id, evidence_bundle_id, role
    FinalClassification Cluster category decision. event_cluster_id, final_category, classification_confidence, method
    SignificanceScore Deterministic significance score. event_cluster_id, final_classification_id, score, band, score_breakdown_json
    ImpactAssessment LLM impact assessment. event_cluster_id, significance_score_id, extended_analysis_json
    DetectedChange The central deliverable. event_cluster_id, competitor_id, title, category, significance, summary, so_what, recommended_action, source_urls_json, source_signal_ids_json, evidence_ids_json, confidence, status
    AlertCandidate An alert queued for dispatch. detected_change_id, reason, payload_json, status
    DigestEntryDraft A prepared weekly-digest entry. detected_change_id, competitor_id, section, priority_order, entry_json
    ProfilePatch A patch applied to a competitor profile. detected_change_id, op, target field, payload
    HistoricalIndexDocument Flattened searchable record. flattened text + metadata
    ReasoningTrace Polymorphic per-step audit rows. step, entity refs, payload
    CompetitorProfile Cumulative per-competitor profile (one per competitor). competitor_id (unique), profile_json, patch_count

    Scoring & agent tables¶

    Model Purpose Key columns
    ScoringWeightProfile Named weight set; exactly one is_active. name, is_active, weights_json, adjustment_log_json
    AgentFeedbackConfig Per-agent prompt addendum + feedback notes. agent_name, prompt_addendum, feedback_notes_json

    Delivery tables (Layer 3)¶

    Model Purpose Key columns
    WeeklyDigest An assembled weekly digest. week_label, subject, status, change_count, competitor_count, html_body, plain_body, sent_at, recipients_json
    DeliveryLog One delivery attempt (email/teams). channel, status, recipients, error_message

    Feedback governance tables¶

    Model Purpose
    AnalystFeedback An analyst verdict on a change/cluster/signal.
    FeedbackSuppressionEntry Legacy Layer 1 suppression (entry_type, value, reason, is_active).
    FeedbackStructuralAction A recorded structural action from feedback.
    FeedbackFeature Deterministic features extracted from feedback.
    FeedbackPattern A mined pattern (status).
    FeedbackChangeProposal A governance proposal awaiting review (status, e.g. pending_human_review).
    SuppressionRule Governance Layer 2 suppression rule.
    SourceReliabilityRule Source reliability multiplier rule.
    HardRule A hard gating rule.
    AgentPolicyRule A policy rule for an agent (agent_name, status).
    CompiledPolicyPack Compiled rules for an agent (agent_name, token_estimate, status).
    PromptCompilationLog Record of a compilation.
    RuleUsageLog Runtime rule-usage record.
    EvaluationCase An eval case.
    EvaluationRun An eval run against a pack.

    Warning

    There are two independent suppression systems: legacy FeedbackSuppressionEntry (Layer 1) and governance SuppressionRule (Layer 2). They are not unified. See Manage Suppressions.

    Observability, cost & incident tables¶

    Model Purpose
    LLMPriceCatalog Active per-model pricing (USD/1k tokens).
    PipelineRun A run spanning Layer 1/2/Delivery (run_type incl. layer2_only).
    CompetitorRun Per-competitor sub-run within a pipeline run.
    AgentRunTelemetry Per-agent telemetry row (workflow, stage, metadata_json, status, timing).
    LLMCostLedger Per-call cost ledger row.
    CurrentRunState Live run state for the observability board.
    Incident An operational incident (severity, status, component).
    MaintenanceAction A maintenance action with an approval lifecycle.
    PolicyPackHealthSnapshot Budget/health snapshot for a pack.
    PolicyConsolidationProposal Proposed consolidation of a pack.
    PolicyCoverageMap Coverage map for a pack.
    PolicyPackSimulationResult Simulated combined-budget result.

    Admin control-plane tables¶

    Model Purpose Key columns
    SourceSchedule One schedule per source (unique FK). source_id, schedule_type, cron_expression, frequency_minutes, timezone, preferred_time, days_of_week_json, jitter_minutes, enabled, next_run_at, last_run_at, last_enqueued_scan_run_id
    ScanRequest A manual scan request. request_type, params_json, requested_by, status, scan_run_id, sources_enqueued, error_message
    CompetitorNewsProfile Rich per-competitor news profile. aliases/brands/markets, query_config_json, relevance_config_json, current_version
    CompetitorProfileVersion Snapshot version of a news profile. profile_id, snapshot JSON, is_rollback
    AdminAuditLog Before/after/diff audit record. object_type, object_id, before/after/diff, IP

    Enums¶

    Defined in app/core/enums.py.

    SourceType:       website_page, website_scope, news_search, careers, blog, social
Frequency:        daily, twice_weekly, weekly, manual
PriorityTier:     Tier1, Tier2, Tier3
ScanRunStatus:    pending, running, completed, completed_with_errors, failed
SourceScanStatus: pending, running, success, failed, skipped
TriggeredBy:      scheduler, manual, test
ArtifactType:     html, json, rss, text, search_results, unknown
SourceItemType:   website_page, news_article, job_posting, blog_post, social_post
SourceItemStatus: active, disappeared, unknown

    Note

    Several status columns carry values beyond the strict enums above — e.g. CandidateSignal.status can be candidate, promoted_to_layer_2, suppressed_source_noise, archived, or needs_review; DetectedChange.status can be ready, archived, archived_fp, or needs_reanalysis. See Item Lifecycle & Status.
