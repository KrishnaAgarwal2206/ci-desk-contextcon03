    API — Competitors, Sources, Runs & Audit¶

    This page is the endpoint reference for the core admin router (app/admin/routes.py) and the scan-request router (app/admin/scan_request_routes.py). It covers the health check, competitor and source CRUD, scan-run management, background scan requests, run visibility, and the audit log. Request and response schemas are defined in app/schemas/admin.py.

    No authentication

    These endpoints have no auth layer — do not expose them to an untrusted network. The changed_by / requested_by / role fields are caller-supplied strings, not verified identities.

    Health¶

    GET /health¶

    Liveness probe. Component: Observability. Backing code: app/admin/routes.py → health().

    Response — 200 OK → hand-built dict

    Field Type Description
    status string Always the literal "ok". 
    // Example 200 response
{ "status": "ok" }

    Status codes: 200 alive.

    Competitors¶

    Competitor records carry the competitor's identity plus keyword lists used across scanning and scoring. Deletes are soft (deactivation).

    POST /admin/competitors¶

    Create a competitor. Component: Control plane. Backing code: app/admin/routes.py → create_competitor().

    Request body — schema CompetitorCreate (app/schemas/admin.py)

    Field Type Required Default Description
    name string yes — Competitor display name.
    description string | null no null Free-text description.
    market_positioning string | null no null Positioning notes.
    tier enum Tier1\|Tier2\|Tier3 no Tier1 Priority tier (PriorityTier).
    aliases_json list[string] no [] Alternate names.
    legal_names_json list[string] no [] Registered legal entity names.
    known_domains_json list[string] no [] Owned web domains.
    brand_names_json list[string] no [] Brand names.
    product_names_json list[string] no [] Product names.
    leadership_names_json list[string] no [] Key people.
    industry_terms_json list[string] no [] Industry keywords.
    negative_terms_json list[string] no [] Terms that exclude a match.
    custom_keywords_json list[string] no [] Extra tracked keywords.
    is_active bool no true Active flag. 
    // Example request body
{
  "name": "Acme Consumer Goods",
  "tier": "Tier2",
  "aliases_json": ["Acme", "Acme CG"],
  "known_domains_json": ["acme.com"],
  "brand_names_json": ["AcmeFresh", "AcmeCare"]
}

    Field Type Description

    leadership_names_json list[string] Key people.
    industry_terms_json list[string] Industry keywords.
    negative_terms_json list[string] Exclusion terms.
    custom_keywords_json list[string] Extra keywords.
    is_active bool Active flag.

    Sources¶

    A source belongs to a competitor and describes one thing to scan. Sources can be created nested under a competitor or flat (the flat form requires competitor_id). Deletes are soft.

    POST /admin/competitors/{competitor_id}/sources¶

    Create a source nested under a competitor. The path competitor_id overrides any competitor_id in the body. Component: Scanning. Backing code: app/admin/routes.py → create_source().

    Path parameters

    Name Type Description
    competitor_id string (UUID) Owning competitor.

    Request body — schema SourceCreate (app/schemas/admin.py)

    Field Type Required Default Description
    competitor_id string | null no null Ignored here — overridden by the path value.
    source_type string yes — Adapter type, e.g. website, news, careers, social.
    name string yes — Source display name.
    url string | null no null Target URL.
    config_json object no {} Adapter-specific config.
    frequency string no "weekly" Scan cadence label.
    priority_override_json object | null no null Per-source scoring overrides.
    is_active bool no true Active flag. 
    // Example request body
{
  "source_type": "website",
  "name": "Acme Newsroom",
  "url": "https://acme.com/news",
  "frequency": "daily",
  "config_json": { "css_selector": ".press-list a" }
}

    Response — 201 Created → SourceOut

    Field Type Description
    id string (UUID) Generated source id.
    competitor_id string (UUID) Owning competitor.
    source_type string Adapter type.
    name string Source name.
    url string | null Target URL.
    config_json object Adapter config.
    frequency string Scan cadence.
    is_active bool Active flag.
    last_scan_at datetime (ISO 8601) | null Timestamp of last scan attempt.
    last_successful_scan_at datetime (ISO 8601) | null Timestamp of last successful scan.
    last_scan_status string | null Status of the last scan.

    Note: SourceOut does not include priority_override_json.

    // Example 201 response
{
  "id": "b71a44f0-…",
  "competitor_id": "9f3c1e28-…",
  "source_type": "website",
  "name": "Acme Newsroom",
  "url": "https://acme.com/news",
  "config_json": { "css_selector": ".press-list a" },
  "frequency": "daily",
  "is_active": true,
  "last_scan_at": null,
  "last_successful_scan_at": null,
  "last_scan_status": null
}

    Status codes: 201 created · 404 competitor not found · 422 validation error (missing source_type/name).

    Scan Runs¶

    A ScanRun groups the sources enqueued for one scan and tracks completion counters.

    POST /admin/scan-runs¶

    Request body — schema ScanRunCreate (app/schemas/admin.py)

    Field Type Required Default Description
    triggered_by string no "manual" Label recorded on the run.

    Scan Requests¶

    A ScanRequest is the high-level, background-executed trigger for a scan. POST returns immediately with 202; the work runs in a background task (_run_scan_in_background) which updates the request status as it progresses. Status transitions: created → running → completed / failed.

    The six request_type values and their params_json shapes (see How-to: Run a Manual Scan):

    request_type params_json Behavior
    all_sources {} Enqueue all due sources (schedule_scan with no filter).
    competitor_sources { "competitor_id": "…" } Enqueue all active sources for the competitor. Fails if competitor_id missing.
    single_source { "source_id": "…" } Enqueue one source. Fails if source_id missing.
    layer2_only { "scan_run_id"?: "…", "competitor_id"?: "…", "limit"?: int } Run the Layer 2 orchestrator only; skips the queue. All keys optional.
    retry_failed { "scan_run_id": "…" } Re-enqueue SourceScanLog rows with status="failed" for that run.
    rebaseline { "source_id": "…" } Clear the source's last_scan_at, then enqueue it.

    POST /admin/scan-requests¶

    Submit a scan request; executes asynchronously in a background thread. Also writes an AdminAuditLog entry (action="trigger_scan", capturing the request payload and caller IP). Component: Control plane. Backing code: app/admin/scan_request_routes.py → create_scan_request().

    Request body — schema ScanRequestCreate (app/schemas/admin.py)

    Field Type Required Default Description
    request_type enum all_sources\|competitor_sources\|single_source\|layer2_only\|retry_failed\|rebaseline yes — Which scan action to run.
    params_json object no {} Parameters for the chosen request_type (see table above).
    requested_by string no "admin" Caller label (unverified).
    role string | null no null Caller role label (unverified). 
    // Example request body
{
  "request_type": "competitor_sources",
  "params_json": { "competitor_id": "9f3c1e28-…" },
  "requested_by": "krishna",
  "role": "analyst"
}

    Response — 202 Accepted → ScanRequestOut (initial state; status is created, scan_run_id still null)

    Field Type Description
    id string (UUID) Scan request id.
    request_type string The submitted request type.
    params_json object The submitted params.
    status string created → running → completed/failed.
    requested_by string Caller label.
    role string | null Caller role.
    scan_run_id string (UUID) | null Set once the background task creates/links a run; null for layer2_only and until then.
    sources_enqueued int Number of sources enqueued (populated on completion).
    error_message string | null Failure reason (null unless status="failed"; truncated to 500 chars).
    created_at datetime (ISO 8601) Creation timestamp.
    updated_at datetime (ISO 8601) Last status update timestamp. 
    // Example 202 response
{
  "id": "e1f2a3b4-…",
  "request_type": "competitor_sources",
  "params_json": { "competitor_id": "9f3c1e28-…" },
  "status": "created",
  "requested_by": "krishna",
  "role": "analyst",
  "scan_run_id": null,

    Run Visibility¶

    These endpoints back the Live Run / Scan Runs polling in the admin panel. They read ScanRun rows and return hand-built dicts (not the ScanRunOut schema), with counters renamed to total_jobs / completed_jobs / failed_jobs and timestamps serialized as ISO 8601 strings.

    GET /admin/runs/current¶

    Return the most recent running scan run, or if none is running, the latest scan run overall; null if no runs exist. Component: Observability. Backing code: app/admin/scan_request_routes.py → get_current_run().

    Response — 200 OK → hand-built dict, or JSON null

    Field Type Description
    id string (UUID) Scan run id.
    status string Run status.
    triggered_by string Trigger label.
    started_at datetime (ISO 8601) | null Start timestamp.
    completed_at datetime (ISO 8601) | null Completion timestamp.
    total_jobs int total_sources_enqueued.
    completed_jobs int total_sources_completed.
    failed_jobs int total_sources_failed. 
    // Example 200 response
{
  "id": "3a55d901-…",
  "status": "running",
  "triggered_by": "manual",
  "started_at": "2026-07-08T05:00:00+00:00",
  "completed_at": null,
  "total_jobs": 12,
  "completed_jobs": 5,
  "failed_jobs": 1
}

    Status codes: 200 ok (body may be null).

    Audit Logs¶

    GET /admin/audit-logs¶

    List admin audit entries (AdminAuditLog) with before/after/diff snapshots and caller IP, most recent first. Component: Observability. Backing code: app/admin/scan_request_routes.py → list_audit_logs().

    This route has no response_model; it returns ORM rows serialized to JSON. The fields below mirror the AuditLogOut schema (app/schemas/admin.py).

    Query parameters

    Name Type Required Default Description
    object_type string no null Filter by audited object type, e.g. scan_request, competitor, source.
    object_id string no null Filter by the audited object's id.
    limit int no 100 Max rows returned.

    Response — 200 OK → list of audit-log objects (AuditLogOut shape)

    Field Type Description
    id string (UUID) Audit entry id.
    object_type string Type of the audited object.
    object_id string | null Id of the audited object.
    action string Action recorded, e.g. trigger_scan, create, update, deactivate.
    changed_by string Caller label.
    role string | null Caller role.
    before_json object | null State before the change.
    after_json object | null State after the change.
    diff_json object | null Computed diff.
    created_at datetime (ISO 8601) When the entry was written. 
    // Example 200 response
[
  {

      "role": "analyst"
