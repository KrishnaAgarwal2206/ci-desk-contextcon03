    Release Notes¶

    This page tracks the version history of the Competitive Intelligence Aggregator, what is currently implemented, the known gaps, and — importantly — the corrections between the older in-repo developer notes (CLAUDE.md / README.md) and the actual code. Where the two disagree, the code (as documented in this site) wins.

    Current version¶

    v0.1.0 — competitive-intel, requires-python >= 3.11. Stack: FastAPI + Uvicorn, Pydantic v2, SQLAlchemy 2.0 + Alembic, httpx / BeautifulSoup / lxml / feedparser, Typer CLI (ci-agent), Azure OpenAI client, Playwright, Azure Service Bus + Blob SDKs, Apify client.

    What's done¶

    • Layer 1 — scanning: all adapters (website, careers, news, blog/social) and all analyzers with LLM integration, behind a cheap deterministic gate.
    • Layer 2 — intelligence: the full 15-step pipeline (normalize → cluster → classify → score → assess) producing DetectedChange plus delivery drafts and cumulative competitor profiles.
    • LLM: AzureOpenAIProvider (gpt-4o via Azure OpenAI) and a deterministic MockLLMProvider for offline tests; single complete_json interface.
    • News: Tavily provider (plus Bing/Brave/Mock auto-detect).
    • Server & UI: FastAPI server with the full single-file admin panel at /admin/panel.
    • Observability: AgentRunTelemetry per-agent metrics, cost ledger, and the Gantt/timeline view.
    • Standalone agents: structured I/O metadata on all agents (the standalone-tool pattern).
    • Feedback: suppression UI to mark signals as noise, plus the governance pipeline (proposals, policy packs, eval harness).

    Known gaps / remaining TODOs¶

    • Azure Service Bus queue — AzureServiceBusSourceScanQueue exists; production wiring/rollout of the separate consumer process is not fully operationalized.
    • Azure Blob store — AzureBlobStore exists; production adoption pending.
    • Alembic migrations — only partially adopted; schema is still mainly create_all + _safe_add_columns (see below and Backup & Migrations).
    • ATS connectors — Greenhouse/Lever/Workday connectors are present but the Workday path falls back to generic HTML; ATS-specific coverage is incomplete.
    • Layer 3 — delivery — digest assembly, email, and Teams exist; broader alert dispatch/scheduling hardening remains.
    • Brave Search provider — available as an alternative to Tavily (BRAVE_SEARCH_API_KEY) but less exercised.

    Documentation corrections vs CLAUDE.md / README.md¶

    The following corrections consolidate drift found across the source material. The older CLAUDE.md and README.md are wrong on these points; this site reflects the real code.

    Topic Older docs say (incorrect) Actual code
    Analyzer package app/analyzers/ (flat <type>_analyzer.py, app/analyzers/registry.py) app/analysis/ with per-type packages (app/analysis/<type>/analyzer.py, app/analysis/registry.py)
    Adapter package flat app/adapters/<type>_adapter.py per-type packages app/adapters/<type>/adapter.py
    Observability routes app/api/observability_routes.py app/admin/observability_routes.py — there is no app/api/ directory; every router lives under app/admin/
    Worker in server mode implies scans run automatically the server only enqueues; nothing consumes the queue automatically — a worker (worker-once / dev-run-once) or a separate Service Bus consumer must run. The server-side scheduler starts only the WeeklyDigestScheduler
    Startup hook (unstated) startup uses the deprecated FastAPI on_event hook, not lifespan — a known migration item
    Config loading (unstated) load-config has no dedup — re-running duplicates competitors and sources

    See Add a New Source Type for the correct extension paths and Deployment for the worker/startup behavior.

    Changelog¶

    v0.1.0 — initial release¶

    • Layer 1 scanning: adapters + analyzers + cheap gate + scan worker + scheduling/queueing.
    • Layer 2 intelligence: 15-step orchestrator, deterministic-first clustering with LLM merge judge, deterministic significance scoring, LLM impact assessment grounded in Godrej Consumer Products (competitors HUL, P&G India, ITC, Marico, Dabur, Reckitt).
    • Layer 3 delivery: weekly digest assembler, email (permissive SSL, skipped when SMTP_HOST unset), Teams cards.
    • Feedback & governance: two suppression subsystems, proposal lifecycle, policy-pack compilation with token budgets, evaluation harness.
    • Observability: telemetry hierarchy, cost ledger (USD + INR at rate 85), pipeline board, live run, timeline, incidents + maintenance actions, Copilot.
    • Azure-ready abstractions for queue, blob, LLM, and database selected at runtime by ENVIRONMENT + connection strings.
    • Single-file admin panel (scripts/admin_panel.html) served at /admin/panel; ci-agent CLI.
